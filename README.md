# UTS Desain Web

Proyek ini adalah contoh halaman login dengan layout split-screen, dibuat menggunakan HTML dan CSS.

## File dan Aset

- `Login.html` — struktur halaman login.
- `Login.css` — tampilan halaman dan layout responsif.
- `Gambar/loginbg.png` — gambar latar untuk panel kiri.
- `Gambar/loginbg-cropped.png` — gambar logo pada formulir.
- `Gambar/icons8-google-48.png` — ikon pada tombol Google.

## Menjalankan

Buka `Login.html` di browser. Pastikan `Login.css` dan folder `Gambar/` tetap berada di lokasi relatif seperti semula.

Halaman ini hanya demonstrasi antarmuka. Tombol login dan Google belum terhubung ke layanan autentikasi, dan formulir tidak mengirim data ke server.
