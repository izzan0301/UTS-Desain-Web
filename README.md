# UTS Desain Web

Halaman login split-screen sederhana yang dibuat menggunakan HTML dan CSS.

## File dan Aset

- `index.html` — struktur halaman login.
- `Login.css` — tampilan halaman, termasuk layout responsif untuk layar kecil.
- `Gambar/loginbg.png` — gambar latar pada bagian kiri halaman.
- `Gambar/loginbg-cropped.png` — gambar yang ditampilkan sebagai logo.
- `Gambar/icons8-google-48.png` — ikon pada tombol Google.

## Menjalankan

Buka `index.html` di browser. Pastikan file CSS dan folder `Gambar/` tetap berada di lokasi relatif seperti semula.

Halaman ini merupakan demonstrasi antarmuka. Tombol login dan Google belum terhubung ke layanan autentikasi, dan formulir tidak mengirim data ke server.
